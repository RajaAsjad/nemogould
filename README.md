# Nemo Gould — Design Preview

Static, mobile-responsive landing page concept for [nemogould.com](https://www.nemogould.com) — kinetic sculpture portfolio rebuild preview (not WordPress yet).

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy (Vercel)

Import this repo in Vercel — framework preset **Other**, output is the repo root. No build step required.

## Assets

Logo, favicon, and sculpture photography sourced from the live client site for design presentation.
